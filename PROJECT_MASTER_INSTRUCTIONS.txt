# 6. CROSS-MODULE INTEGRATION – MOST IMPORTANT PART

The most important part of AgriLink is connecting the outputs of the four modules.

We want the platform to combine agricultural production, mandi prices, store demand and inventory risk to provide more useful agricultural insights.

Do not simply merge all four raw datasets. Their granularities, time periods and geographical coverage are different.

## A. Crop Production + Mandi Price Integration

Our selected datasets:

**Crop Production:**
- Agricultural-year data.
- State and district information.
- Crop names.
- Production in tonnes.
- Area in hectares.
- Yield in tonnes per hectare.

**Mandi Prices:**
- Daily observations.
- Calendar dates.
- State and district.
- Market and commodity.
- Minimum, maximum and modal prices.
- Prices generally recorded in rupees per quintal.

### Our agreed integration approach

Instead of processing all mandi records, select:

1. One common state initially.
2. Three to five common crops.
3. A common period supported by both datasets.
4. A compatible geographical level.

Start with state-level integration because state-level matching is more manageable than district-level matching.

### Step 1: Identify common crops

- Compare `crop_name` with `Commodity`.
- Standardize spelling, capitalization and whitespace.
- Create a controlled crop-name mapping table.
- Do not assume similar names always represent identical commodities.
- Account for commodity varieties where relevant.
- Document unmatched crops.

### Step 2: Identify common states

- Compare `state_name` with `State`.
- Standardize state names.
- Create a mapping table for state-name variations.
- Check actual state coverage in both datasets.

### Step 3: Select the common time period

The crop-production dataset uses agricultural years, for example:

- 2021–2022
- 2022–2023

The mandi dataset uses daily calendar dates.

Do not assume that these periods are automatically equivalent.

Inspect the actual date coverage and establish a documented agricultural-year mapping. Aggregate daily mandi observations to monthly prices first, and then to the corresponding agricultural year using the verified date convention.

Only use years that are genuinely available in both datasets.

Our initial target is to investigate the overlapping period around 2021–2025, but do not assume all those agricultural years exist in the crop-production dataset. The earlier inspection showed only 2021–2022 and 2022–2023 in the recent subset.

### Step 4: Aggregate mandi data

For the selected state, crops and time period:

- Aggregate daily Modal_Price into monthly average prices.
- Calculate annual/agricultural-year average price.
- Calculate minimum and maximum prices.
- Calculate price volatility.
- Count the number of observations.
- Check missing months and insufficient observations.

Keep the aggregation method consistent and documented.

### Step 5: Create the integrated dataset

The integrated dataset should contain fields such as:

| Column | Description |
|---|---|
| Agricultural_Year | Common agricultural period |
| State | Standardized state |
| Crop | Standardized commodity |
| Production_Tonnes | Actual crop production |
| Area_Hectares | Cultivated area |
| Yield | Crop yield |
| Average_Mandi_Price | Aggregated modal price |
| Minimum_Price | Aggregated minimum price |
| Maximum_Price | Aggregated maximum price |
| Price_Volatility | Price variation |
| Observation_Count | Number of mandi observations |

Use actual values from the source datasets. Never create fake production or price values to fill missing records.

### Example structure

| Agricultural Year | State | Crop | Production | Average Mandi Price |
|---|---|---|---|---|
| 2021–22 | Selected state | Wheat | Actual dataset value | Actual aggregated value |
| 2022–23 | Selected state | Wheat | Actual dataset value | Actual aggregated value |

The example is illustrative. Populate it only after successfully merging actual data.

### Important interpretation rule

This integration provides compatible state-level annual records. It does not prove that a particular mandi's price is directly caused by production in the corresponding state.

Production-price analysis must be presented as an association, not a causal conclusion.
